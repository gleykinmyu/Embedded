## Функционал

### F1. Поведение клетки (телеметрия → модель → нажатие)

Сейчас `refreshCell` рисует только Blocked / Isolated / Ready / Selected+Ready.
Нажатие не знает Fault / чужой holder / Nack.

- **Чужой `holder`:** не слать Select; MsgBox «занято пультом N».
- **Fault:** не выделять; MsgBox; сброс — когда `resetFault()` на пульте станет не `false`.
- **Moving:** оставить выделенной; цвет не как Select; снятие Select — по политике (пока нет Stop/`SetTarget` — не блокировать deselect без нужды).
- **Limit:** не запрещать нажатие (обычно едут в другую сторону); достаточно цвета/пометки.
- **Нет связи / нет телеметрии:** высота «—», клетка не Active.
- Обновление высоты **с порогом** (Δ мм или ≤10 Гц на клетку), иначе 24 оси забьют UART 250000.

### F2. Nack / session callbacks до UI

Select уходит в CAN; Busy / NotReady / SelectLimit на экране нет.

- Перекрыть `Node::onAck` / `onNack` на консоли → MsgBox / состояние клетки (не ждать телеметрию).
- SelectLimit (`kMaxSelected = 3`) — явный текст.
- `Node::onStatus`: IdConflict / LinkError → StatusBar / MsgBox; close сессий по политике app.
- Listen ~T до первого ping (`MConsole`), затем `startSession` (PROTOCOL IdConflict).
- Позже diag: `onPktIdGap` — RX class A не previous+1 (только `requiresAck`; флаг/sentinel «первый кадр»; лог, сессию не рвать). Сейчас есть только `onPktIdMismatch`.

### F3. StatusBar

Левая колонка сейчас `min NNNk` (отладка кучи).

- Оператору: связь (`IConsole::linkUp()`), конфликт id, режим Work / Блок / Спектакль.
- Память — только debug-сборка или длинный тап по бару.

### F4. Настройки пульта (не шоуфайл)

Страница: RTC + `isolateGroup`. Вход только из **Файл**, только Work.

- **Яркость:** `dim=` (сейчас 100 в `Program.s`). Хранить на пульте (W25Q / backup RTC).
- **Номер пульта (`console_id`):** сейчас зашит в `CanLink`; нужен из‑за `IdConflict`.
- Доступ хотя бы к яркости и часам в режиме Спектакль (не через меню файла).

### F5. `isolateGroup` и `SETT`

8 байт в шоуфайле, 7 reserved. Свитч → `markEdited()` → `*`.

- Решить: привычка оператора (память пульта) или свойство постановки (файл).
- Операторское — вынести из `SETT`. Шоу — писать без `*`.
- В reserved не класть дисплей и id пульта; место под параметры шоу, когда появится движение.
