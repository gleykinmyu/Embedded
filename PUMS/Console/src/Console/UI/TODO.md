# Пульт — план

Сентябрь 2026. Идти сверху вниз. Протокол и модель оси — `src/smcp/ANALYSIS.md`.

Nextion `NX1060P101`, кадр 600×1024, проект `src/PUMS 2.5.HMI`. Правки HMI: Editor → Compile → `.tft`. CLI нет.

## Не трогать

- Геометрию и нумерацию клеток на `work`. Раскладка = лебёдки в зале, дыра `b24` — пустое место сцены.
- Затемнитель `t0` на `mFile` / `mGroup`. StatusBar рисуется оверлеем поверх HMI.
- Клетки McUI-оверлеем поверх кнопок. `bco` / `txt` делают `ref` и затирают canvas.
- Настройки baud 250000, CAN 1 Мбит, `DriveMech::kMaxSelected`.
- Поездку в высоту на экране, пока в SMCP пустой `DriveMech::setTarget`.
- Rope / Chain и `cfgpio` в HMI, пока нет инвентаря и назначения ног.

## Дальше

### 1. Контраст и заглушки HMI

Кнопки `#292829` тонут в фоне `#101410`. Disabled сейчас равен цвету страницы. В HMI зашиты «Натан Мудрый», «01 -», «1»…«24».

- Поднять `bco` обычной кнопки (ориентир `#3A3A3A` в RGB565).
- Клеткам и строкам групп — `isbr=1`, как у Файл / Блок / Спектакль.
- Disabled: отдельный mute-fill и приглушённый текст, не цвет страницы.
- Blocked: янтарная обводка, заливку `#521418` оставить.
- Янтарь `#FFA500` (selected / спектакль) не менять.
- Пустые `txt` у файлов, групп, заголовков браузера. Стартовые цвета = Disabled.
- Разделители даты на `settings` (`t8` / `t9`) — точки, не двоеточия.
- Цвета синхронно в `appColors.hpp`, `buttons.hpp` и `.HMI`.

### 2. Страница настроек

Сейчас RTC + `isolateGroup`. Вход только из Файла и только в Work. Свитч isolate пишет в `SETT` и ставит `*` через `markEdited()`.

- Яркость: `dim=` (сейчас 100 в `Program.s`). Хранить на пульте (W25Q или backup RTC), не в шоуфайле.
- Номер пульта на этой же странице. Сейчас зашит как `1` в `Console/main.cpp`. Куда писать id и как снова звать `begin` — в плане SMCP.
- Решить isolate: привычка оператора или свойство постановки. Операторское — вынести из `SETT` и не ставить `*`. Шоу — писать без `*`, если больше ничего не менялось.
- В reserved шоуфайла не класть яркость и id пульта.
- Пока isolate только красит кнопку. Recall группы изолированные оси всё равно выделяет — это чинится в модели SMCP, не вторым `if` на Press.

### 3. Клетка

`refreshCell` рисует Blocked / Isolated / Ready / Selected+Ready. Нажатие не знает Fault, чужой holder и «кадр не ушёл».

Один `font` на кнопку: номер крупный, высота мельче — второй объект, не оверлей.

- Кнопка `b0`…`b23`: тач, цвет статуса, номер (font1).
- Рядом `Text` (font2, `sta=3`, `tsw=0`, id после кнопки): высота цифрами.
- Не `xstr` поверх кнопки и не Progress Bar.
- `WinchButton::setPrefix` для высоты не использовать: он пишет в `txt` кнопки тем же шрифтом.
- Цвета Busy / Moving / Fault / Limit — расширение `StateColors`, не новые виджеты.
- Чужой holder: не слать Select, MsgBox «занято пультом N».
- Fault: не выделять, MsgBox. Кнопка сброса заработает, когда в SMCP появится `resetFault`.
- Moving: клетка остаётся выделенной, цвет не как Select. Deselect не блокировать, пока нет Stop.
- Limit: нажатие не запрещать, достаточно цвета.
- Нет связи или нет телеметрии: высота «—», клетка не Active.
- Высоту обновлять с порогом (Δ мм или не чаще 10 Гц на клетку). Иначе 24 оси забьют UART 250000.
- Nack уже открывает MsgBox (`showSmcpNack`), в том числе SelectLimit. Не добавлять второй разбор кода.
- MsgBox и синхронизацию клетки не открывать синхронно из `Node::update`: UART панели тормозит pump CAN.

### 4. StatusBar

Левая колонка сейчас `SD`, статус узла и `min NNNk`.

- Оператору: связь (`ServerSession::isOpen`), конфликт id, режим Work / Блок / Спектакль.
- Память — только debug-сборка или длинный тап по бару.

### 5. Настройки из Спектакля

Яркость и часы доступны в режиме Спектакль, не через меню файла.

Режим Спектакль сейчас только гасит пункты меню. `onLoad` страниц не смотрит mode: HMI page по UART открывает файл и RTC в обход `assignOk()` кнопки Файл. Запрет Select в этом режиме — в модели SMCP, guard страницы — здесь.

### 6. Кнопка Block на клетке

Клетка при включённом Block шлёт сегментный `Block` (`CMech::block`): все пульты, снятие Select. Кнопка группы в том же режиме пишет только флаг GRUP в шоуфайле.

На экране развести подписи и жест. Куда уходит маска с клетки — решается вместе с планом SMCP, не вторым цветом той же кнопки.
