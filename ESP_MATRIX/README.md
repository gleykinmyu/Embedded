# WJ-SX550 — RS-232 протоколы

Заметки по трафику Panasonic WJ-SX550 + пульт (WV-CU550) и PC-порту.
Источник: sniff пульта (`sniff_session.log`, COM12/COM13 @ 9600 8N1) и тесты PC (COM14 @ 19200 8O1).

## Два разных интерфейса

| | Пульт (CU) | PC port |
|---|---|---|
| Скорость | **9600 8N1** | **19200 8O1** |
| Префикс тела | **нет** (`H02MS`) | **`CMD:`** (`CMD:H02MS`) |
| Адреса в кадре | `01` (CU) / `10` (матрица) | обычно без addr-обёртки CU |
| PTZ | `L01ACF…` | `CMD:CmmPT…` (на SX550A **не двигает** камеру) |
| Меню камеры | `S01AID…` | `CMD:CmmCM…` (на SX550A **не открывает** OSD) |

Команды с пульта короче: без `CMD:`, без лишнего padding вроде `C02PT001` + бинарных xx/yy.

---

## Кадр пульта (System Controller)

```
ENQ-запрос:   <addr> 05  STX  <addr>  <body>  ETX  <addr> 04
ACK:          <addr> 06
```

Пример логина с пульта:

```
01 05 02 01 57 30 31 2D 31 32 33 34 35 03 01 04
          |  |  W  0  1  -  1  2  3  4  5  |
          STX addr         body            ETX
```

- **COM13** → матрица (TX пульта, addr `01`)
- **COM12** ← матрица (TX матрицы, addr `10`)

Ответ матрицы: `10 05 02 10 <ans> 03 10 04`, на каждый кусок — ACK `01 06`.

## Команды пульта → матрица

Тела ниже — то, что внутри STX…ETX (без addr).

### Логин / сессия

| Действие | Команда | Ответ |
|---|---|---|
| Логин user1 / 12345 | `W01-12345` | `WOK` |

### Монитор / камера

| Действие | Команда | Пример |
|---|---|---|
| Выбрать монитор | `HmmMS` | `H01MS` … `H06MS` |
| Выбрать камеру на текущем mon | `HmmCScc` | `H02CS01` = mon2→cam1 |

Номера камер >9 идут ASCII за `'9'`:  
`H02CS0:` = cam **10**, `H02CS0;` = cam **11** (`:` = 0x3A, `;` = 0x3B).

### PTZ (джойстик)

Формат движения: `L01ACF` + **ось** + `B` + **скорость (3 байта)**.

| Действие | Ось | Пример потока |
|---|---|---|
| **Влево** | `H` | `L01ACFHB@@@` → `…BB@@` → `…BC@@` → `L01ACBD` |
| **Вправо** | `L` | `L01ACFLB@@@` → `…BB@@` → `…BC@@` → `L01ACBD` |
| **Вверх** | `J` | `L01ACFJB@@@` → `…B@B@` → `…B@C@` → `L01ACBD` |
| **Вниз** | `N` | `L01ACFNB@@@` → `…B@B@` → `…B@C@` → `L01ACBD` |
| **Стоп pan/tilt** | — | `L01ACBD` |

Скорость: `@` = `0x40`, дальше `A`/`B`/`C`… — разгон.  
Pan: скорость в **1-м** байте после `B` (`B@@@` / `BB@@` / `BC@@`).  
Tilt: скорость во **2-м** байте (`B@B@` / `B@C@`).

Пока джойстик держат — пакеты повторяются (~1 Гц на полной скорости).

### Зум

| Действие | Команда |
|---|---|
| Зум одно направление (tele/wide) | `L01ABBL` |
| Зум другое | `L01ABBH` |
| Стоп зума | `L01ABBD` |

(Какое из L/H = tele, уточнять отдельным прогоном «только tele» / «только wide».)

### Меню камеры (OSD)

| Действие | Команда |
|---|---|
| Открыть меню | `S01AID@` |
| Навигация | `S01AID` + литера |
| Выход / confirm? | `S01AIDA` (в конце сессии навигации) |

Литеры навигации из сессии:

| Литера | Наблюдение |
|---|---|
| `D` | движение по меню (часто) |
| `B` | движение |
| `J` | движение |
| `E` | движение |
| `C` | движение |
| `K` | движение |
| `A` | вероятно Enter / выход |
| `@` | open menu |

Точный map «вверх/вниз/влево/вправо/Enter/Esc» — нужен ещё один размеченный прогон только по меню.

`H02PS` в первом (плохом) заходе меню — похоже на **preset/spot**, не OSD.

## Фоновый трафик матрицы → пульт

Даже без действий пульта матрица шлёт статус **~каждые 5 с**:

```
N02BC01 → N02Z010 → HN02R11 → HC01R11 → C01Z01…… → HZ016 → WOK
```

| Пакет | Смысл (по контексту) |
|---|---|
| `NmmBCcc` | mon `mm` смотрит cam `cc` |
| `NmmZ010` | статус zoom/zone mon |
| `HNmmR11` | monitor held / linked |
| `HCccR11` | camera held / linked |
| `CccZ01…` | телеметрия камеры (позиция/зум, поля `?`) |
| `HZ016` | heartbeat / unit id |
| `WOK` | сессия жива |

Пульт в простое отвечает только ACK (`01 06`).

## PC-порт (для сравнения)

Логин / коммутация работают:

```
CMD:W1-12345     → ANS:WOK
CMD:H02MS
CMD:H02CS001     → ANS:HN002R / HC001R  (формат ответа длиннее)
```

PTZ/меню в стиле SX150/650 (`CMD:C02PT…`, `CMD:C02CM…`) на этом SX550 **ACK есть, движения/OSD нет**.
Рабочий PTZ/меню для этой железки — путь пульта: `L…` / `S…` (или эмуляция кадра CU).
